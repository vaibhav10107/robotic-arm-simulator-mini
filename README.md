# robotic-arm-simulator-mini

A lightweight, offline simulation tool for robotic arms using Python and Pygame.

> This project provides a simple, offline simulation tool for robotic arms, useful for developers and researchers in robotics and AI.

## Features

- pytest coverage of the core behaviour
- Verified by tests: Run 'python test_simulator.py' to ensure the simulator runs without errors.

## Requirements

- Python 3.11+
- Stack: Pygame

## Install

```bash
git clone <this-repo>
cd robotic-arm-simulator-mini
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
python -m pytest
```

Example output:

```text
A window should open displaying a white screen, simulating a robotic arm.
```

## Tests
